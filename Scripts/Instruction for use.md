# 🛠️ Chat Log Cleaner (聊天记录清洗脚本)

这个小工具是专门为了配合我们的 **Pro 复杂版提示词模板** 而设计的。它可以帮你自动过滤掉从社交软件（如微信、QQ等）导出的原始聊天记录中的时间戳、系统通知（如撤回、红包、转账等）等噪音，提取出最纯净的对话文本，方便你快速提取角色的“语言指纹”并填入 Few-Shot 示例中。

---

## 💡 运行逻辑 (How it works)

### 1. 原始聊天记录（噪音多）
原始的聊天记录通常长这样，充满了无法被大模型直接利用的“噪音”：
```text
2026-05-22 17:00:00 傲娇学姐
学弟，你代码又写出 Wild Pointer 啦？
2026-05-22 17:01:05 系统消息
对方撤回了一条消息
```
### 2. 清洗后聊天记录（纯净格式）
经过本脚本清洗后，会输出变成最适合 AI 学习的干净格式：

Plaintext
傲娇学姐: 学弟，你代码又写出 Wild Pointer 啦？

### 🚀 使用方法 (Usage)
请按照以下步骤在本地运行脚本：

#### 1  下载脚本

将本文件夹下的 clean_log.py 下载到你的电脑本地。

#### 2  准备语料

从你的聊天软件中导出文本格式（.txt）的聊天记录，并将其重命名为 raw_chat.txt。

#### 3  放置目录

将 raw_chat.txt 移动到与 clean_log.py 相同的文件夹目录下。

#### 4  修改脚本入口

打开 clean_log.py，将最下方的 pass 注释掉，解除倒数第二行的注释：

Python
   if __name__ == "__main__":
       clean_chat_log("raw_chat.txt", "cleaned_chat.txt")
#### 5  运行脚本

打开终端或命令行（Terminal），运行以下命令：
```text
Bash
   python clean_log.py
```
#### 6  获取结果

运行完成后，同目录下会生成一个 cleaned_chat.txt。现在你可以打开它，尽情挑选最能体现角色灵魂的经典对话片段，直接复制到你的高级 Prompt 模板中了！

### 🔧 自定义扩展 (Extension)
如果你导出的聊天记录包含特定软件特有的系统提示（例如 [语音]、[视频通话]），你可以随时在代码中的 noise_keywords 列表中添加对应的关键词，脚本就会自动帮你把它们过滤掉啦。
